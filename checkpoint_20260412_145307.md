# Project Checkpoint — 2026-04-12 14:53:07

## Project Overview

Named Entity Recognition (NER) recovery research project. The goal is to train
a model to infer redacted named entities from text. Training corpus is drawn
from World War I Wikipedia articles.

---

## What We Have Built

### Data Pipeline (complete)

Three sequential stages:

| Stage | Script | Input | Output |
|---|---|---|---|
| Fetch | `fetcher.py` | Wikipedia API | `wwi_corpus.jsonl` (145 articles, raw wikitext) |
| Clean | `scripts/janitor.py` | `wwi_corpus.jsonl` | `data/wwi_clean.jsonl` (plaintext) |
| Redact | `scripts/redactor.py` | `wwi_clean.jsonl` | `data/wwi_redacted.jsonl` (text + redaction annotations) |

Redaction is seeded at 42, sampling 2–5% of spaCy-detected entities per article (minimum 1).

### Model (complete)

- **Architecture**: DistilBERT (`distilbert-base-uncased`), encoder-only Masked Language Model
- **Task framing**: Entity token positions are masked in `input_ids`; model learns to predict original tokens from surrounding context
- **Training**: `src/ner_recovery/train.py` — 3 epochs, batch size 8, lr 5e-5, AdamW + linear warmup, 512-token sliding window (stride 256)
- **Evaluation**: `src/ner_recovery/eval.py` — exact-match accuracy, top-1 token prediction per mask position, broken down by NER label

### Package

Installable via `uv sync`. Entry points: `build-corpus`, `train`, `evaluate`.

## Accuracy Improvements

### Fix #1 — Multi-token eval mismatch (applied, confirmed improvement)

**Problem**: `eval.py` replaced every `[REDACTED]` with a single `[MASK]` token
regardless of how many tokens the original entity had. Multi-token entities
(e.g. "Franz Ferdinand", "Western Front") could never achieve an exact match.
This was silently killing accuracy on PERSON, ORG, EVENT, FAC, and several
other categories.

**Fix**: For each redaction, tokenize `r["original"]` to get token count N,
insert N `[MASK]` tokens, predict each position independently, decode and join,
then compare to the original. Change was limited to `eval.py` — no retraining
needed.

**Result**:

| | Baseline | Fix #1 | Delta |
|---|---|---|---|
| Overall | 37.95% | 67.17% | +29.22 pp |
| EVENT | 0.00% | 48.96% | +48.96 pp |
| FAC | 0.00% | 52.63% | +52.63 pp |
| ORG | 15.64% | 61.32% | +45.68 pp |
| PERSON | 14.55% | 55.91% | +41.36 pp |
| GPE | 70.20% | 93.47% | +23.27 pp |
| DATE | 27.90% | 57.94% | +30.04 pp |

Eval reports saved in `evals/`.
